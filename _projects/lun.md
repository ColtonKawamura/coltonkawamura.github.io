[**lun**](https://coltonkawamura.github.io/lun/) is a low-dependency task and project tracker for macOS, built for agents and the humans who supervise them. Agents file, move and annotate tasks with plain CLI calls; every change lands in a git-style history that can be read in slices. The same SQLite board backs a drag-and-drop web kanban board (installable on a phone and usable offline) and a full-screen terminal UI.

The site walks through the board, the CLI, the TUI and the details — links dragged from a browser or Mail, live markdown notes with KaTeX, PRs attached to tasks, and one directory to back up. Source: [ColtonKawamura/lun](https://github.com/ColtonKawamura/lun).
